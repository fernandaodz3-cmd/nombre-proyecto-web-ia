##  Sobre el proyecto
Sitio personal con biografía, hobbies e identidad visual, creado para el reto del curso. Generado con apoyo de herramientas de IA.

###  Tecnologías e IA utilizadas:
- **ChatGPT**: para redactar biografía y descripciones de hobbies.
- **Copilot / Playground u otra IA generadora de imágenes**: para generar imágenes (hobbies, logo, mockups).
- **HTML + CSS puro**: diseño y estructura.
- **GitHub Pages**: despliegue del sitio.
